# library-system
Library System API using Java, Spring Boot and Maven

This project was made to practice Java, Spring Boot, software architecture, unitary tests, git, Docker,and software design.

## Goals
- ✅ Core library model 
- ✅ In-memory repositories
- ✅ Unitary tests 
- ✅ Basic CLI implementation
- Spring Controllers
- Integrate PostgreSQL and migrate to JPA
- Spring view technologies
- Spring Security
- Docker Container

## Technologies

- Java 17+
- Maven
- Spring Boot
- JUnit 5
- Jackson 3
- JaCoCo

## Implemented Concepts
- Spring HATEOAS
- RESTful API
